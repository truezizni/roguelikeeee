# Roguelikeeee

Маленький ASCII-рогалик на Rust и [macroquad](https://macroquad.rs/): комнаты и коридоры, поле зрения, пошаговые бои, монстры, зелья, золото и бесконечный спуск вниз.

```
####################
#..................#
#..@....r..........#
#.......####.......#
#..........#...!...#
#....o.....#.......#
#..........#.......#
#........#######...#
#........#.........#
#........#....>....#
####################
```

## Возможности

- генерация подземелья из комнат и коридоров;
- поле зрения с запоминанием исследованных клеток;
- пошаговые бои: ударил — монстры ответили;
- четыре вида монстров (крыса, гоблин, орк, тролль) с простым ИИ;
- предметы: зелья лечения, мечи (+1 к атаке), золото;
- HUD с HP, глубиной, атакой, зельями, золотом и убийствами;
- смерть и рестарт по `R`;
- детерминированная генерация по seed (уровень всегда воспроизводим).

## Запуск

Нужен Rust 1.87+ и X11 (Linux).

```bash
cargo run --release
```

На Debian/Ubuntu могут понадобиться библиотеки:

```bash
sudo apt install -y libx11-dev libxi-dev libgl1-mesa-dev pkg-config
```

## Управление

| Клавиши | Действие |
|---|---|
| `WASD`, стрелки, `HJKL` | ход / атака в сторону монстра |
| `Y` `U` `B` `N` | ход по диагонали |
| `.` или `Space` | подождать один ход |
| `g` | поднять предмет под собой |
| `q` | выпить зелье |
| `Enter` или `>` (`Shift`+`.`) | спуститься по лестнице |
| `R` | начать заново |
| `Esc` | выход |

Золото подбирается автоматически, когда ты наступаешь на него.

## Механики

- **HP**: 20/20 на старте. Зелье восстанавливает 8 HP, но не выше максимума.
- **Атака**: 2 на старте, каждый меч даёт +1. Урон = атака + случайная добавка 0..2.
- **Монстры**: просыпаются, когда видят игрока, и преследуют его. Спят — бродят случайно.
- **Глубина**: с каждым спуском монстров больше и они сильнее. Лестница отмечена `>`.

## Структура проекта

```
src/
  main.rs      — окно, ввод, игровой цикл
  game.rs      — состояние игры, ходы, бой, ИИ
  map.rs       — тайлы, генерация уровня, FOV, поиск пути
  entity.rs    — игрок, монстры, предметы
  ui.rs        — отрисовка карты, HUD и экрана смерти
assets/        — шрифт DejaVu Sans Mono и его лицензия
```
